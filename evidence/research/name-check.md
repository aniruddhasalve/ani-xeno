# Ani Uni name check

Checked 2026-11-23 before repository creation.

A web search for `Ani Uni font`, `Ani Universal typeface font`, and `Ani Uni GitHub font` did not surface an obvious existing font project. GitHub repository search also did not surface an obvious exact-name font repository. This is a practical preliminary check, not a trademark clearance or a guarantee that the phrase has never been used anywhere.

The public repository therefore uses `ani-uni` and the family name `Ani Uni`. Before a commercial launch, perform a formal trademark and domain check.
