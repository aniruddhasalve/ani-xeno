# Ani Uni coverage plan

## First release target

The first usable release will cover Basic Latin, Latin-1 punctuation, common currency signs, mathematical operators, arrows, UI symbols, and tabular/proportional numerals where technically supported.

## Later releases

Extended Latin comes next. Devanagari and other scripts will be planned as separate design milestones with native-language review. No script will be labeled supported until shaping, mark placement, line breaking, and representative words have been tested.
