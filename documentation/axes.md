# Ani Uni variable axes

The variable-font plan is part of the product definition, not an afterthought.

`wght` controls hierarchy from regular UI text to strong headings. `wdth` allows short mobile labels to fit without resorting to arbitrary tracking. `opsz` tunes spacing, joins, and proportions for small UI text versus large display text. `GRAD` changes perceived darkness while preserving line breaks, which is useful when a device or platform renders a font lighter or heavier than expected.

Axis ranges will be finalized only after the first master designs and interpolation tests exist.
